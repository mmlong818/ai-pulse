Anthropic’s Claude Max plans still use five-hour usage limits

Anthropic当前官方资料仍将最高档套餐列为Max 5x和Max 20x，并说明Claude与Claude Code共享五小时用量限制；额外的周度或其他限制仍可能适用。

当前公开状态

Anthropic当前官方套餐说明仍将100美元方案列为Max 5x，将200美元方案列为Max 20x，并未显示最高档套餐已改名为Ultra。官方帮助文档仍以五小时窗口描述Max用户的用量限制，同时说明Claude与Claude Code的活动会共享适用额度。

这意味着，至少从Anthropic目前公开的计划和帮助页面看，五小时用量窗口仍是Max用户需要考虑的产品约束。公开资料没有确认所谓“Ultra”改名或已验证账户取消五小时限制的普遍政策。

为什么重要

五小时限制仍是高频Claude和Claude Code用户体验中的核心变量，尤其会影响长时间运行的编码任务。即使Anthropic提高了某些产品或账户的额度，额度提升也不等于取消滚动窗口，更不等于无限使用。

用户还需要区分不同产品的限制：Claude、Claude Code和桌面端活动可能计入共享或适用额度，而具体上限会随套餐、模型、工具使用、消息长度和系统负载变化。官方页面因此更适合作为当前状态的依据，第三方重置时间表不能单独证明套餐名称或限制已经改变。

Uncle Cat take

截至目前，Anthropic公开资料支持的是Max 5x和Max 20x及五小时用量窗口，而不是“Ultra取消五小时限制”；连续编码体验是否改善，仍应以账户实际显示和官方更新为准。
