Moonshot launches Kimi K3.1 Pro with 3T-class scale

Moonshot’s new Kimi K3.1 Pro combines a 1M-token context window, tool use and multimodal workflows with immediate API access.

What happened

Moonshot AI introduced Kimi K3.1 Pro on October 23, describing it as a 3T-class flagship model and making both the API and a faster K3.1 Pro Highspeed variant available immediately. The company’s launch posts position the model for long-context reasoning, coding, financial analysis and 3D workflows rather than as a narrow chatbot upgrade.

The model supports a context window of up to one million tokens. Moonshot says it can work directly with Blender, Unreal Engine, Godot and CAD tools, extending the model’s role from text generation into structured design and engineering tasks. The company also reported a 64.4 score on OfficeQA Pro v2 and internal gains over Kimi K3 in financial modelling and financial research.

Early third-party signals are notable but should be read carefully. Artificial Analysis placed K3.1 Pro among the stronger systems for agentic knowledge work and coding, while Arena reported a median task cost of $1.23 for the Max offering and a price of $2 per million input tokens and $10 per million output tokens. Those figures describe selected evaluations and workloads, not a universal cost advantage.

Why it matters

K3.1 Pro matters because Moonshot is packaging a very large open-model-style architecture around practical tool use and a relatively transparent API price, while targeting work that usually requires premium proprietary systems. The combination could intensify competition in long-context agents, software development and technical design. The unresolved question is whether its reported breadth survives independent testing on reliability, latency and sustained multi-step execution. If it does, the strategic shift is larger than another leaderboard launch: Chinese model providers would be competing directly for global professional workflows, not only for consumer chat traffic.

Uncle Cat take

A million-token window is attention-grabbing, but the decisive detail is K3.1 Pro’s direct integration with Blender, Unreal, Godot and CAD: Moonshot is pricing a model as a workbench, not merely a narrator.
