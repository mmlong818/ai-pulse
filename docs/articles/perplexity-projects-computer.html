Perplexity turns Spaces into Projects for all users

Perplexity rebuilt its Spaces feature as Projects, persistent workspaces for its Computer agent with a shared file system and connection to the Brain memory layer.

Perplexity launched Projects on Thursday, replacing its Spaces feature with persistent workspaces built around its agentic product, Computer. The company said Projects are available immediately to all users.

What changed

Where Spaces functioned largely as a research collection — a place to group threads and reference files — Projects are structured around ongoing agent work. Each Project carries a shared file system that Computer can read, edit and write across sessions, so output from one task becomes input to the next rather than being discarded when a conversation ends. Perplexity describes Projects as hubs for managing, creating and collaborating on tasks, with multiple people able to work in the same Project.

The more consequential piece is the connection to Brain, the self-improving memory system Perplexity introduced for Computer in June. Between tasks, Brain reviews a Project's accumulated files and session history and updates its internal model of the work, so a new task begins with context from everything that came before rather than a cold start. Perplexity has previously reported that Brain improves answer correctness by 25 percent and recall by 16 percent on tasks requiring historical context, while cutting cost per task by 13 percent. Brain itself has been rolling out in research preview to Max and Enterprise Max subscribers.

The launch follows a rapid sequence of Computer releases: a Windows desktop client on 28 July, the SPACE sandboxed runtime that now backs all Computer sessions, and a Model Council feature that runs a single question across several frontier models in parallel.

Why it matters

Agent products have converged on a shared bottleneck: work does not accumulate. Each session starts fresh, and users compensate by re-uploading context or re-explaining projects. Attaching a durable file system and a memory layer to a named container is a structural answer rather than a longer context window, and it is the same direction Anthropic, OpenAI and Cursor have taken with project-scoped memory and persistent agent environments. Shipping it to every tier, rather than gating it behind a $200 plan, also puts pressure on rivals reserving persistence for premium subscribers.
