Midjourney Opens V8.2 Image Editing to Testers

Midjourney’s first V8.2 editing model adds instruction-led changes, four-image references, inpainting and canvas expansion.

A native editor for the V8 generation

Midjourney has begun broad community testing of its first image-editing model built for V8.2. Users can modify an existing picture with written instructions, regenerate selected regions through inpainting, extend a composition beyond its original borders and generate new images from as many as four visual references.

The new reference workflow replaces Midjourney’s earlier Omni Reference mechanism for these editing jobs. Personalization profiles, moodboards and style references remain available, although the company warns that moodboards and style references may need more explicit prompting during the test.

Users can attach images directly to the web prompt bar, open an existing result and select Edit, upload through a dedicated editing tab, or invoke the model on Discord with an edit command. Midjourney has also modified the interfaces on its main and alpha websites, indicating that the editing model is being tested together with the workflow surrounding it rather than as an isolated endpoint.

A test release with acknowledged gaps

Midjourney is explicitly treating this as a larger community test, not a finished production release. It is asking users to flag unsuccessful generations and submit job identifiers or links for difficult cases. The company expects rapid follow-up changes to both the model and interface.

That qualification matters because instruction-based editing is judged differently from unconstrained image generation. A visually attractive result can still fail if it alters protected details, mishandles one reference among four or changes areas outside the user’s selection. Midjourney has not yet published systematic measurements for edit fidelity, identity retention or reference consistency.

Why it matters

The release moves Midjourney further from a prompt-to-image generator toward an iterative visual-production environment. Native editing can reduce the need to transfer generated work into another product for revisions, while multi-image conditioning could make recurring subjects and art direction easier to preserve. Whether it becomes a dependable professional tool will depend on precise local control—the part Midjourney is now asking its community to stress-test.
