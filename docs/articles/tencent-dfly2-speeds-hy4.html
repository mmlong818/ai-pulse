Tencent Open-Sources DFly2 to Speed Up Hy4 Inference

Tencent has released DFly2, a speculative-decoding drafter for Hy4 flash that claims up to 4.2× faster inference on long-context and agent workloads.

Tencent’s Hunyuan team has open-sourced DFly2, a speculative-decoding drafter designed to accelerate inference for its Hy4 flash model. In a post published on November 26, the team said the system can deliver up to a 4.2× speedup for long-context and agentic workloads.

The bottleneck it targets

Speculative decoding uses a smaller draft model to propose several next tokens before a larger model verifies them. When the draft is accurate, the main model can accept multiple tokens in one pass, reducing the number of expensive sequential decoding steps. DFly2 is intended to make that process more effective for Hy4 flash, particularly when prompts are long or an agent repeatedly calls the model while using tools.

Tencent also said Hy4 flash had gone live on Fireworks AI, giving developers access to production inference infrastructure. The model was additionally promoted as free on OpenCode for a limited period, suggesting that Tencent is using distribution and developer experimentation to increase usage alongside the open release.

The 4.2× figure is a peak claim, not a universal guarantee. Actual gains depend on draft acceptance rates, prompt structure, output length, hardware, batching and the surrounding agent framework. Long-context applications can also be limited by memory bandwidth and tool latency rather than token generation alone.

Why it matters

The release highlights a shift in open-model competition. The important asset is no longer only the model checkpoint; it is the inference stack that determines whether a large model can be used economically in real products. A faster drafter can reduce serving cost without retraining the flagship model, provided its predictions remain accurate enough to be accepted.

For agent developers, this matters because multi-step workflows amplify every generation delay. If DFly2 performs close to Tencent’s best-case numbers outside controlled tests, Hy4 flash could become more competitive in coding, research and tool-use workloads. The unresolved question is whether the speedup survives diverse prompts and production traffic rather than benchmark-style traces.
