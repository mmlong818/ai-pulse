OpenAI Rolls Out GPT-6 With Interactive Chat Interfaces

OpenAI is turning ChatGPT answers into live interfaces with charts, controls and small tools, expanding the chatbot beyond text.

What happened

OpenAI began rolling out GPT-6 with a feature called Intelligent UI to ChatGPT Plus, Pro, Business and Enterprise users worldwide. Free and Go users are scheduled to receive it the following day. The release is powered by GPT-6 Sol for paid plans and GPT-6 Luna for the lower-cost tiers, while Codex and ChatGPT Work remain on their existing models.

Intelligent UI allows ChatGPT to combine prose with graphics, charts, forms, buttons and small interactive tools. A user asking for a savings calculation, trip plan or educational explanation can receive a purpose-built interface inside the conversation rather than a static answer. OpenAI says the system uses a library of native, streamable components and a compiler that renders them progressively as the model generates its response.

The model can also begin answering while it continues reasoning or using tools, then add further findings. OpenAI reports that GPT-6 Instant starts web-search answers 44% faster than GPT-5.6 Instant in an internal evaluation, although the company has not published an independent benchmark covering the new interface behavior.

Why it matters

This is a product-strategy shift as much as a model release. ChatGPT is being positioned as a surface that can assemble lightweight software on demand, potentially absorbing tasks that once required spreadsheets, dashboards or specialized apps. The constraint is reliability: an interface that looks useful but makes a faulty calculation or hides important assumptions can be more dangerous than plain text. OpenAI’s rollout therefore tests whether generated interfaces become a trusted working layer or remain an attractive presentation feature.
