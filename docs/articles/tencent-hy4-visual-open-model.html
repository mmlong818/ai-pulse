Tencent launches Hy4 with vision and agent upgrades

Tencent has launched Hy4 with visual understanding, stronger long-context reasoning and agent capabilities, while promising open weights in the coming days.

Tencent has launched Hy4, a new generation of its Hunyuan model, positioning it as a stronger general-purpose system for coding, office work, research and long-running agent tasks.

The release adds visual understanding to the Hy line for the first time. Tencent says Hy4 can process images, analyze complex charts and support mathematical reasoning that depends on visual information. The company also points to improvements in instruction following, long-context comprehension, tool use and multi-step work.

The timing matters because Hy4 is being introduced as a product model before its final open release. Tencent said model weights and system cards will arrive in the coming days, meaning today’s launch expands access through Tencent products and cloud services but does not yet constitute a new open-weight release under a strict definition.

Hy4 also arrives with a distribution advantage. Tencent is making it available across products including WorkBuddy and CodeBuddy, and is offering discounted access through Tencent Cloud TokenHub. That gives the model an immediate path into workplace software rather than leaving it as a benchmark entry or developer preview.

The main unresolved question is how much of the claimed progress survives independent testing. Tencent’s previous Hy4 preview already had a large mixture-of-experts design and a very long context window, so the significance of this release will depend less on headline scale than on measured reliability in visual tasks and sustained agent workflows. If the weights and system card arrive as promised, Hy4 could become one of the most consequential Chinese open-model releases of the current cycle.
