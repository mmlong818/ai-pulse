Z.ai launches GLM-5.4 with a looped coding architecture

Z.ai’s new 750B flagship reuses layers to deepen reasoning, targeting long-horizon coding, cybersecurity, 3D design and physical-control tasks.

A deeper model without proportionally more parameters

Z.ai has introduced GLM-5.4, a 750-billion-parameter flagship built around what the company calls a Loop Transformer. Rather than adding a separate set of layers for every reasoning step, the model runs 28 shared layers twice, allowing the second pass to refine representations produced by the first.

Z.ai says the design raises capability without multiplying the full memory footprint. Its hybrid key-value cache shares most context between loops while retaining a local sliding window for newly generated information. Sparse-attention indexes are also reused, and the company says deployment costs rise well below proportionally at million-token context lengths.

Coding as a general-purpose capability

The release is positioned as more than a coding upgrade. Z.ai describes “Generalized Coding” as using software generation to extend model capability into video creation, game development, 3D experiences, mechanical design and cybersecurity. Demonstrations include a self-narrated music video, a six-axis robotic arm modeled in FreeCAD, a complete game and an interactive scene built with GLSL shaders.

The company reports throughput of up to 200 tokens per second off-peak and 70–80 tokens per second during peak load. It also says the model can produce shorter explicit reasoning traces on several benchmarks because some computation is shifted into the internal loop.

Why it matters

GLM-5.4 is available through Z.ai’s coding products, while API access is listed as coming soon. The weights are not yet public, so this is a commercial model launch rather than an open-weight release. The consequential question is whether looped depth can deliver durable gains on messy, multi-stage engineering work without making inference too expensive or causing the model to overthink. Z.ai acknowledges that “marathon thinking” remains a limitation.

Uncle Cat take: GLM-5.4’s important bet is architectural: 28 reused layers may buy deeper reasoning, but the missing API and closed weights leave its real efficiency claims unpriced.
