OpenAI Builds Pando to Scale Git for Agents

OpenAI built a new Git backend for its monorepo, targeting the parallel pushes, fetches, and recovery needs created by engineers and coding agents.

A Git backend for a different workload

OpenAI has built Pando, a new backend for Git designed to support the company’s monorepo as both human engineers and software agents generate more concurrent activity. The project was disclosed in an engineering post published on November 2.

Pando preserves the familiar Git client workflow while changing how repository data is stored and transferred. When a client fetches updates, Pando identifies the missing commit range and returns links to packfiles that cover the gap. When multiple engineers or agents push to different branches, the system can process those updates in parallel. Updates targeting the same branch remain ordered.

The design also addresses failure recovery. OpenAI says it contributed fixes upstream to Git for cleanup after interrupted packfile downloads, suggesting that the work exposed edge cases relevant beyond its own infrastructure. The company describes late-push latency as falling substantially after the migration, though the post does not provide a full independent benchmark or disclose the total size of the repository.

The significance is less about Git itself than about the software-production environment OpenAI is building around it. Coding agents create bursts of automated commits, branch operations, and repository reads that conventional developer tooling was not designed to absorb efficiently. A backend that can parallelize traffic without forcing engineers to adopt a new interface could become an important layer in agent-heavy development organizations.

Why it matters

The post offers a concrete infrastructure signal: agents are changing the shape of routine software operations before they replace the operations themselves. If Pando’s approach generalizes, repository systems may increasingly be optimized for machine-generated concurrency rather than only for human collaboration.

Uncle Cat take

Pando’s upstream Git fixes are more revealing than its branding: interrupted downloads became a product problem because agents keep the pipeline busy.
