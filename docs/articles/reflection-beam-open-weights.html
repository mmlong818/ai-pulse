Reflection Releases 501B Beam Model Under Apache 2.0

Reflection has released Beam’s weights and tooling, opening a 501-billion-parameter coding model built for long-horizon agent workloads.

Reflection has released the weights for Beam, its first open-weight model, under the Apache 2.0 license. The release makes available a sparse mixture-of-experts model with 501 billion total parameters and 23 billion active parameters, alongside a model card, safety report, deployment integrations, and customization tooling.

An open stack around the model

Beam is aimed at coding, reasoning, and long-horizon agent tasks. Reflection says the model supports a one-million-token context window and offers instruction-tuned checkpoints in BF16, FP8, and NVFP4 formats. The company is also publishing recipes for fine-tuning and reinforcement learning, with planned self-distillation workflows that use verified task traces to improve accuracy and token efficiency.

The release is unusually broad at launch. Reflection lists more than 40 partners and integrations, including cloud providers, inference platforms, model tools, and coding environments. That gives developers several ways to test Beam without operating the full model themselves, while preserving the option to download and self-host the weights.

The model is text-only and was developed predominantly for English. Reflection’s public claims emphasize inference efficiency, but independent evaluation remains important because the company’s headline comparisons rely on selected coding and reasoning benchmarks. The total parameter count also says little about the hardware and serving complexity required by a 23-billion-active-parameter model with a million-token context.

Why it matters

Beam is significant because it combines open weights with a coordinated deployment and customization ecosystem. That makes it more commercially usable than an isolated checkpoint and gives enterprises a path to domain-specific tuning without surrendering all control to an API provider.

The release also raises the bar for open models aimed at agentic coding. If Beam’s efficiency claims hold across independent workloads, it could pressure closed providers on price and deployment flexibility. If the model proves difficult to serve or underperforms outside curated evaluations, its partner list will matter less than expected. The weights are public now; the durable verdict depends on real-world operation.
