Cursor agents gain read-write access to Google Workspace

Cursor shipped plugins letting its agents read and write across Gmail, Drive, Calendar, Docs, Sheets and Chat, pushing a coding tool into general knowledge work.

What shipped

Cursor released a set of Google Workspace plugins on August 3 that give its agents direct read and write access to a user's Google account. Per the company's changelog, the coverage is broad: Gmail search, reading, drafting, sending and label management; Drive search, file opening, creation and organisation; Calendar reading, event creation and updates; Docs opening, reading and editing; Sheets range reads, cell updates and spreadsheet creation; and Google Chat space and message access. The plugins install from the Cursor Marketplace or the Customize page inside the app.

The same day, Cursor said its cloud agents had become 20–30% more token efficient on general runs and roughly 80% more efficient on runs involving computer use, attributing the gains to changes in how the agents handle MCP servers, skills and computer-use loops.

The shift it represents

Cursor built its business on a code editor. Gmail and Calendar are not code. The plugins mark the point at which a coding agent stops being scoped to a repository and starts operating over the rest of an engineer's working surface — filing a ticket's context from an email thread, updating a spec doc after a merge, or reading a calendar before scheduling a long-running job.

It also lands in a contested lane. Google itself has been opening Workspace to third-party agents through a preview MCP server and a Workspace CLI carrying more than a hundred prebuilt agent skills, which Claude Desktop, Gemini CLI and VS Code already connect to. Cursor's move is to ship first-party plugins rather than leave users to wire up an MCP server themselves.

Why it matters

Write access to a user's inbox, drive and calendar is a materially different risk surface than write access to a git branch. A prompt-injected email is now a plausible path to an agent sending mail or altering a shared document, and the industry has no settled answer for scoping those permissions. For the market, it signals that the coding-agent category is expanding into general enterprise agents — which puts Cursor into direct competition with Google's and Microsoft's own productivity assistants rather than only with other IDEs.
