Alibaba's Qoder coding agent arrives on mobile

Alibaba has released Qoder Mobile across Android, iOS and HarmonyOS, letting developers steer its coding agents and cloud tasks from a phone with feature parity across platforms.

Coding agents in your pocket

Alibaba has launched Qoder Mobile, bringing its agentic coding platform to smartphones with Android, iOS and HarmonyOS versions released together and, the company says, identical in functionality across all three. The app is a companion to Qoder's CLI and desktop tools rather than a standalone editor: it lets developers remotely monitor an agent's progress, approve or reject actions, answer the agent's questions and issue new instructions from a phone, and it can delegate tasks to run in the cloud.

Qoder is Alibaba's "agentic programming platform for real software," first opened to global users in 2025 and advanced to version 1.0 in May 2026, when it was positioned as a shift from an AI IDE toward an autonomous development workbench that can execute, verify and deliver work end to end. The mobile release extends that workflow off the desktop, targeting the increasingly common pattern of long-running agent tasks that a developer wants to supervise while away from their machine.

Why it matters

The launch is a small but telling move in the coding-agent race. As agents take on multi-step engineering work that runs for minutes or hours, the interface for supervising them — approving a risky file change, unblocking a stuck run — becomes as important as the model doing the work. Putting that control loop on a phone, and shipping simultaneously on HarmonyOS alongside Android and iOS, signals Alibaba's intent to compete with Western coding-agent products such as Devin and Claude Code on convenience and reach within the Chinese and broader Asian developer market, where mobile-first supervision and HarmonyOS support carry real weight. It also reflects a broader industry bet that the human's role is shifting from writing code to steering the agents that write it.
