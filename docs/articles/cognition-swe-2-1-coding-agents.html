Cognition releases SWE-2.1 for faster coding agents

Cognition’s SWE-2.1 uses reinforcement learning on Kimi K3 and adds Cyber and Lightning variants aimed at long-horizon software work.

What happened

Cognition released SWE-2.1, a coding model trained with pure reinforcement learning on Kimi K3. The company is making it available across Devin Cloud, Devin Desktop and Devin CLI, alongside two specialized variants: SWE-2.1 Cyber for cybersecurity work and SWE-2.1 Lightning, delivered through Cerebras for much higher speed.

Cognition reports a score of 50.0 on Terminal-Bench 4.1, up from 24.2 for SWE-2, and 41.3 on FrontierCode 2.0, compared with 24.1 for the previous model. The company says the model’s training targets general intelligence and long-horizon workflows rather than narrow code completion, which it argues explains gains in cybersecurity and other tasks.

The headline performance is not uniformly frontier-leading. In Cognition’s published comparison, SWE-2.1 scored below GPT-6.2 Sol and Claude Opus 5.5 on several listed benchmarks, while outperforming older SWE-2 by wide margins. Cognition also positions the Lightning variant as approaching frontier intelligence at roughly ten times the speed through Cerebras hardware.

Why it matters

The release shows coding-agent competition moving beyond a single model into a portfolio strategy: a general coding model, a security-focused version and a low-latency serving path. That matters because agent economics depend on how quickly a system can inspect repositories, run tools and iterate, not only on its score in a static test.

The unresolved question is whether benchmark gains translate into reliable pull requests and long-running maintenance work. Cognition’s own numbers establish a substantial step over SWE-2, but do not yet show that the model consistently beats the strongest general-purpose frontier systems in production.

Uncle Cat take: SWE-2.1’s 24.2-to-50.0 Terminal-Bench jump is substantial, but the real commercial wager is whether Lightning’s speed survives messy repositories.
