Perplexity's Personal Computer agent lands on Windows

The desktop agent reads local files, drives Office apps and routes subtasks across 20-plus frontier models, gated behind Perplexity's $200-a-month Max tiers.

Perplexity brought Personal Computer, its desktop agent product, to Windows 10 and 11 on 28 July, moving the software from a research preview into direct competition with Microsoft's own Copilot on Microsoft's own platform.

How it works

The local application takes a task description plus context about the user's files and active applications and sends it to Perplexity's cloud, where an orchestrator — Claude Opus 4.7 by default — decomposes the request into subtasks and routes each to whichever of more than 20 available models fits best. Execution then touches the local machine: creating and editing Word documents, updating Excel workbooks, reorganising files, running multi-step research and stitching workflows across applications. Perplexity says it can pull data from over 400 connected services into local files and works with existing Excel, PowerPoint, Word and Outlook installations.

Distribution is deliberately narrow. The Windows release is rolling out first to Max and Enterprise Max subscribers on the waitlist, plans starting at $200 per month, and Perplexity has not announced a timeline for broader availability or for lower tiers. That is a tighter gate than Computer itself: the hosted product is listed as available on Pro, Max, Enterprise Pro and Enterprise Max so long as credits remain, with Max subscribers getting monthly credits and higher spend limits than Pro. Access to hosted Computer and access to the Windows desktop agent are separate entitlements. Perplexity also added Model Council to Computer this week, letting users run the same analysis across several frontier models and receive one cited synthesis, and added Moonshot's Kimi K3 to its roster on US-hosted servers only.

Why it matters

Desktop agents are where the agent thesis meets its hardest constraint: real filesystems, proprietary file formats and applications with no clean API. Perplexity's answer is architecturally distinctive — it does not train the models it orchestrates, and instead bets that routing across a rented frontier is better than owning one. That makes the product a live test of whether a model-agnostic layer can hold a position against a platform owner shipping a first-party assistant in the operating system.

The pricing is the other signal. At $200 a month for the entry point on Windows, Perplexity is positioning Personal Computer as a per-seat replacement for hours of knowledge work rather than a consumer add-on — the same framing rivals have used for coding agents, now applied to the general office desktop. Whether local file and application access at that price survives enterprise security review is the open question.
