Perplexity open-sources SPACE for safer AI agents

Perplexity has open-sourced SPACE, a sandbox platform that isolates computer-using agents while preserving task state through snapshots.

Perplexity has open-sourced SPACE, a sandbox platform for agentic products that execute commands, install packages and call external services. The company presents it as the sandbox platform behind Perplexity Computer, aimed at making computer-using agents safer to deploy.

SPACE is designed for agents whose work is long-running, stateful and branching. Each task runs in an isolated Firecracker microVM that is destroyed when the task ends, while rolling snapshots preserve session state for pause, resume and forking. This lets an agent continue after interruptions without implying that the underlying sandbox remains permanently alive. The platform also provides per-session credential isolation, protocol forwarding and node-level outbound network controls.

Perplexity says it tested the design against frontier models. Its report evaluated nine model configurations across 216 total runs. The VM-escape task accounted for 108 of those runs, and no model reached the host from the guest VM. The report separately tested network confinement, where some partial-network bypasses were initially observed and then reevaluated. The company’s accompanying security write-up argues that isolation has to be treated as a persistent runtime property, not merely as a permission attached to a single tool call.

The release arrives as more products move from chat responses toward computer operation. That shift changes the security problem: an agent can install software, manipulate files and interact with third-party services over a period long enough for a small mistake or malicious instruction to compound. Ephemeral execution combined with snapshots is intended to support this pattern without treating a long-lived guest environment as inherently safe.

Why it matters: SPACE tackles a foundational bottleneck in agent deployment rather than adding another model interface. Open-sourcing the component could give developers a reference for durable agent sessions and layered isolation, but the public evidence remains narrow. Testing across the reported VM and network boundaries does not establish safety against every host, kernel, supply-chain or credential failure, so adoption will depend on independent audits and operational evidence.
