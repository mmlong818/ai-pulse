DeepSeek V4 Pro 转正，重点强化智能体能力

0813 正式版已覆盖网页、移动端和 API，并加入 Responses API、分档推理强度及新一轮智能体能力升级。

从预览版进入正式商用阶段

DeepSeek 已将 V4 Pro 升级为正式版本，新的 0813 构建开始覆盖网页端、移动应用和 API。API 侧继续沿用 deepseek-v4-pro 这一模型名称，因此现有应用无需修改调用标识，就可能直接切换到新版本。

此次更新的重点是智能体任务，而非改变模型的基础规模。DeepSeek 此前公布的参数保持不变：V4 Pro 是总参数 1.6 万亿、单次激活 490 亿参数的混合专家模型，上下文窗口为 100 万令牌。官方数据显示，0813 版本在软件工程和工具调用评测上取得明显提升，包括 Terminal-Bench 2.1 得分 87.9、Toolathlon-Verified 得分 74.1、DeepSWE 得分 62.7。不过，这些仍是厂商自行披露的成绩，尤其是长时间运行的智能体，其实际可靠性还会受到外部执行框架、工具配置和错误恢复机制影响，仍需第三方复测。

更直接地接入编程智能体

DeepSeek API 现已原生兼容 OpenAI Responses API 格式，并提供面向 Codex 兼容环境的配置方式。V4 Pro 和 V4 Flash 同时增加 low、high、max 三档推理强度，让开发者无需切换模型，也能在响应速度、令牌成本与推理深度之间进行取舍。

DeepSeek 还宣布，新的高峰与低谷分时价格将于 8 月 16 日生效，低谷时段价格为高峰时段的一半。此次上线时并未同步公开经过新一轮后训练的 0813 权重，因此它属于托管模型正式版更新，而不是一次新的开放权重发布。

这次升级的重要性在于，DeepSeek 争夺的已不只是模型榜单名次，而是编程、研究等智能体的实际执行入口。原生 Responses API、百万上下文和分档推理控制，都降低了开发者从其他供应商迁移到 DeepSeek 的成本。如果官方披露的智能体增益能够通过独立验证，V4 Pro 将进一步压低前沿智能体模型的价格，同时为全球开发者提供一个更具竞争力的非美国方案。
