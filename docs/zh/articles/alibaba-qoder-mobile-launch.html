阿里 Qoder 编程智能体登陆移动端

阿里发布 Qoder Mobile，安卓、iOS、鸿蒙三端同步上线且功能一致，让开发者在手机上遥控其编程智能体与云端任务。

把编程智能体装进口袋

阿里推出 Qoder Mobile，将其智能体编程平台带到手机端，安卓、iOS、鸿蒙三大版本同步上线，官方称三端功能层面完全一致。该 App 是 Qoder CLI 与桌面工具的伴侣，而非独立编辑器：开发者可远程查看智能体进度、批准或拒绝操作、回答智能体的提问、下发新指令，并可将任务委派到云端运行。

Qoder 是阿里"面向真实软件的智能体编程平台"，2025 年首次面向全球用户开放，2026 年 5 月升级至 1.0，被定位为从 AI IDE 迈向可端到端执行、验证、交付的自主开发工作台。此次移动端发布把这一工作流延伸到桌面之外，瞄准日益常见的场景——长时间运行的智能体任务，开发者希望在离开电脑时仍能监管。

为何重要

这次上线在编程智能体竞赛中是一个不大却颇具意味的动作。随着智能体承担起动辄数分钟乃至数小时的多步工程任务，监管它们的界面——批准一次有风险的文件改动、为卡住的运行解锁——变得与干活的模型同等重要。把这套控制回路搬上手机，并让鸿蒙与安卓、iOS 同步发布，显示出阿里意在中国及更广泛的亚洲开发者市场，以便利与触达和 Devin、Claude Code 等西方编程智能体产品竞争——在这一市场，移动端优先的监管与鸿蒙支持颇有分量。它也折射出业界更大的判断：人的角色正从写代码，转向驾驭那些写代码的智能体。
