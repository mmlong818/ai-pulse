Perplexity 将 Spaces 升级为 Projects，全量开放

Perplexity 把 Spaces 重构为 Projects——面向 Computer 智能体的持久工作区，配备共享文件系统并接入 Brain 记忆系统。

Perplexity 周四推出 Projects，以围绕其智能体产品 Computer 构建的持久工作区取代原有的 Spaces 功能，并称该功能即日起向所有用户开放。

变化在哪

Spaces 此前更像一个资料集合——用来归拢对话线程和参考文件；Projects 则是围绕持续进行的智能体工作组织的。每个 Project 自带一套共享文件系统，Computer 可以跨会话读取、编辑和保存其中的文件，于是上一个任务的产出会成为下一个任务的输入，而不是随着对话结束一并作废。Perplexity 将 Projects 定位为管理、创建与协作任务的中枢，多人可以在同一个 Project 中协同。

更关键的是与 Brain 的打通——这是 Perplexity 6 月为 Computer 推出的自我改进型记忆系统。在两次任务之间，Brain 会回顾该 Project 累积的文件与会话记录并更新自己对这项工作的理解，使新任务从"已有全部前情"开始，而不是冷启动。官方此前给出的数据是：在依赖历史上下文的任务上，Brain 让答案正确率提升 25%、召回率提升 16%，单任务成本下降 13%。Brain 本身仍以研究预览形式面向 Max 与 Enterprise Max 订阅用户推送。

此次发布延续了 Computer 的密集迭代节奏：7 月 28 日上线 Windows 桌面客户端，此前推出的 SPACE 沙箱运行时已承载全部 Computer 会话，另有可让同一问题在多个前沿模型上并行分析的 Model Council 功能。

为何重要

智能体产品正撞上同一个瓶颈：工作不会累积。每次会话都从零开始，用户只能靠反复上传资料、重新交代背景来弥补。把持久文件系统和记忆层挂到一个具名容器上，是比"再加长上下文窗口"更结构化的解法，方向上也与 Anthropic、OpenAI、Cursor 在项目级记忆和常驻智能体环境上的做法一致。把它一次性开放给所有档位、而非锁在 200 美元套餐之后，也给那些把"持久化"当作高级订阅卖点的对手施加了压力。
