OpenAI前沿模型与Codex将登陆Google Cloud

OpenAI将通过Google Cloud提供前沿模型和Codex代理工作流，企业可在现有云治理体系内采购和部署。

OpenAI与Google Cloud宣布，OpenAI的前沿模型及Codex代理式工作流将进入Google Cloud的Model Garden。企业客户可通过Google Cloud Marketplace采购，并使用既有的云消费承诺完成支付，无需另行建立一套采购关系。

双方计划在未来几周开放正式可用。OpenAI还表示，其模型将陆续接入Google Antigravity和Gemini Agent，使合作不止于传统模型目录，也延伸到Google的开发者和代理产品。微软仍是OpenAI的主要云合作伙伴。

对企业买家而言，关键并非多了一个API入口，而是模型采购和治理方式发生了变化。Google Cloud客户可以在熟悉的环境中评估OpenAI模型，并继续使用现有的身份管理、数据策略、账单、网络和基础设施体系。对于不愿把敏感工作负载迁移到另一朵云上的监管行业，这会明显降低试用成本。

这笔合作也提升了Google Cloud的竞争力。Google如今可以在一个大型云市场中同时提供Gemini、Claude和OpenAI模型，把模型选择变成采购层面的能力，而不是一次平台押注。OpenAI则获得了新的企业分发渠道，同时没有放弃与微软的主合作关系。

真正效果仍取决于后续细节：价格、地区覆盖、数据处理条款和具体模型阵容，决定它是实质性的多云接入，还是又一项停留在公告层面的合作。但无论如何，前沿模型公司正在越来越依赖企业已经采购和治理软件的地方来完成交付。

猫叔判断

Google真正赢在把多模型选择变成采购流程；OpenAI扩大触达，却也让Google更能决定企业先试哪个模型。
