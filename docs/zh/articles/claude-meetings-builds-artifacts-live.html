Anthropic推出 Claude Meetings，让智能体参与实时会议

Claude Meetings 首先接入 Google Meet，以可见参会者身份记录讨论、整理行动项，并在会议进行时生成文档和白板。

从会议记录员变成参会者

Anthropic 发布 Claude Meetings，将 Claude 直接放进团队视频会议。目前产品首先支持 Google Meet，未来计划扩展到更多会议平台。

Claude 并不是一个隐藏在后台的转录工具，而是以可见参会者身份出现。会议过程中，参会者可以通过语音或聊天向它提问，也可以让它当场开始制作文档、白板或其他工作成果。

会议结束后，Claude 会在专门的会议页面中整理笔记、行动项和完整转录，并保留会议期间创建的内容。这样一来，会议记录不再只是被归档的文件，而是可以继续推进工作的协作空间。

智能体价值的一次现实考验

这项产品的重要性在于，它把 Claude 放进高频、快速变化且错误容易被当场发现的协作场景。会议智能体必须判断哪些内容是最终决定，哪些只是试探性想法，还要在多人发言之间准确保留任务负责人。它还必须足够有用，却不能打断会议，或制造一套没人维护的额外工作。

Anthropic 让 Claude 成为可见参会者，也是一种信任设计。同事可以看到它何时在场，随时质疑输出，并在讨论仍未结束时修正文档。相比会后默默录音、交付一份不透明总结，这种方式把纠错直接放进流程。

为什么重要

Claude 正从个人助手走向团队协作界面。只要生成的成果足够准确、可编辑，会议就可能成为委派工作的起点，而不只是谈话的终点。隐私同意、机密讨论、说话人识别，以及修正一份看似专业却错误的行动清单，仍是产品必须解决的问题。

猫叔判断： “可见参会者”是这次发布最关键的设计，它让纠错发生在会议现场，而不是藏在会后转录文件里。
