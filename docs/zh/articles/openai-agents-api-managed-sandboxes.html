OpenAI开放智能体API，提供托管沙箱运行环境

OpenAI推出公开测试版智能体API，开发者可直接调用托管沙箱，让具备工具和文件能力的智能体在云端运行。

OpenAI宣布将智能体API（Agents API）开放至公开测试阶段，为开发者提供一套托管式构建和运行方案，让智能体在云端协调模型调用、工具使用与上下文。

这次发布了什么

该API包含由OpenAI托管的沙箱环境，智能体可以在其中执行代码、处理文件、安装软件包并生成可交付产物。开发者也可以接入自有沙箱或第三方环境，并按工作负载选择CPU、GPU和内存配置。

OpenAI的关键做法，是把“智能体循环”放在自己的基础设施上运行：平台负责协调模型调用、工具执行和上下文，开发者则定义智能体可以使用的能力以及运行位置。这样，从原型走向持续运行的云端工作流时，需要自行编写的编排代码会明显减少。

这次发布也说明，OpenAI的开发者平台正在从单轮文本生成，转向可持续执行任务、调用工具并产出文件的系统。代码执行、文件操作、安装依赖和生成产物等运行层能力，被打包进了同一套服务。

为什么重要

对于企业产品而言，这可能降低部署类似Codex智能体的门槛；但与此同时，OpenAI也在掌握应用基础设施中越来越关键的一层。开发者获得了速度和便利，也可能更依赖OpenAI的运行时、价格体系与安全边界。

真正尚未验证的是，托管沙箱能否以可预测的成本支撑稳定的生产任务。公开测试代表平台方向已经明确，但还不等于成熟的运营模式。
