Sakana Chat 新增浏览器代码执行

升级后的 Namazu 日语助手可把日语描述直接变成可运行的应用、游戏、图表和文档，无需注册即可免费使用。

从问答助手转向可执行工作台

总部位于东京的 Sakana AI 对 Sakana Chat 进行了大规模升级，接入新一代日语模型 Namazu，并新增浏览器内代码执行功能。服务目前仍可免费使用，用户无需注册账号即可开始对话；注册后则能保存历史记录并获得更高的使用额度。根据其常见问题页面，Sakana Chat 目前仅限日本境内使用。

升级后的执行环境允许用户直接用日语描述想要的应用、工具或游戏，系统生成代码后可在聊天界面中立即运行。Sakana 展示的使用场景包括学习练习题、简单网页游戏、电子表格分析、图表生成以及演示资料制作。这意味着 Sakana Chat 不再只是回答问题，而是开始成为一个能够生成、运行和检验实际成果的轻量级智能体工作台。

Namazu 是 Sakana 将高性能基础模型适配到日语、当地文化和日本本土需求的模型系列，同时尽量保留通用推理与编程能力。Sakana Fugu 则是另一项独立的商业 API 产品，可动态选择并协调多个底层模型。Sakana 当前公开的产品页面没有确认 Fugu 已成为 Sakana Chat 内部的模型或编排层，因此不能把两项产品描述成同一次整合发布。此次 Chat 更新也没有同步发布新的 Namazu 独立权重，应视为在线服务升级，而非开放权重发布。

为何值得关注

当前多数编程智能体首先围绕英文开发者工作流设计。Sakana 选择把可执行生成能力直接提供给日本用户，包括消费者、学生和办公人群，同时用免登录方式降低首次尝试门槛。电子表格分析和资料制作等示例，也让它更接近通用知识工作智能体，而不只是编程聊天机器人。

浏览器内执行代码本身并非独有功能，这次更新的意义在于，Sakana 将日本本土化后训练与可运行产物整合进了同一个公共产品。后续的用户采用情况与任务可靠性，将检验本土化智能体能否对支持日语、但并非围绕日本工作方式和文化语境设计的全球助手形成持久优势。Fugu 的多模型 API 是 Sakana 产品战略中的另一部分，但应与 Sakana Chat 已确认的功能分别评估。
