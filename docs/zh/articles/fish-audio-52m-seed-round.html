Fish Audio 完成 5200 万美元种子轮，ARR 已达 2100 万

这家起步于研究者单卡业余项目的语音生成公司称已有 800 万用户，但把最新的模型留在了付费 API 里。

语音生成公司 Fish Audio 完成 5200 万美元种子轮融资，由 Coreline Ventures 与今日资本联合领投，359 Capital、Parable、Play Time、Alphalist Partners、Bayhouse Ventures、Carya Venture Partners 及 HF0 跟投。

从业余项目做到有收入

公司源自前英伟达研究员廖士家的个人尝试——他用一块 GPU 训出一个语音生成模型并选择开源。由此而来的 Fish Speech 仓库已累积超过 3.1 万 GitHub star，在独立开发者、游戏工作室和创作者群体中形成了口碑。对一家此前未拿机构资金的公司而言，这是相当罕见的开源基本盘。

目前 Fish Audio 称年度经常性收入（ARR）为 2100 万美元，创作者、开发者与企业客户合计超过 800 万用户。过去一年公司发布了五个模型：四个语音生成、一个语音识别。其中三个语音生成模型已开源，但最新的 S2.1 Pro 仅通过付费 API 提供。新资金将投向下一代模型研发，以及承接企业需求所需的基础设施；音频理解模型计划年内推出，语音到语音模型正在开发中。

为什么重要

在生成式媒体里，语音是商业模式最先跑通的那一块。图像和视频模型至今仍难把关注度转化为可持续收入，而语音合成已经切入配音、游戏制作、无障碍、有声书，并越来越多地成为对话式 agent 的语音层——ElevenLabs 正是在这一层构筑阵地。在已有 2100 万美元 ARR 的基础上还能拿到这个量级的种子轮，说明这个品类不再被当作投机赛道。

更值得琢磨的细节是它的许可策略：先用开源权重换取分发与信誉，再把最强的模型留在手里变现。「底座开源、前沿闭源」这条路径正在成为生成式媒体领域小型实验室的默认打法，也是前沿大厂那场开源权重争论的一个更安静、但可能更持久的版本。它同时留下一个公司尚未回答的问题：那些帮它建起用户群的开源仓库，还能不能继续拿到它最好的成果。
