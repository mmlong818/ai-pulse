Krea上线Motion编辑器，主打可编程AI动态图形

Krea推出浏览器端Motion编辑器，将提示词与预设工作流用于生成动态文字、界面动画和动态图表。

发生了什么

Krea 于 11 月 26 日推出 Krea Motion，一款基于浏览器的 AI 动态图形编辑器。公司表示，相关工作流现已向所有用户开放，并提供免费试用。

Motion 面向动态文字、界面动画和动态图表等结构化视觉任务。它并非把每次生成都当作一段视频，而是将可复用的动态图形工作流和可编辑的场景逻辑封装在浏览器工具中。对于动态图形制作而言，这一点很关键：此类内容通常需要精确的时间控制、重复布局和稳定几何结构，而传统扩散式视频模型在这些方面往往不够可控。

Krea 的公告尚未公布完整技术规格，包括输出分辨率、片段时长限制、商业授权条款和 API 是否开放。部分第三方报道将其描述为偏代码驱动、可用于自动化创意工作流，但在 Krea 发布更完整文档前，这些细节仍应谨慎看待。

为什么重要

这次发布体现了生成式媒体从单张图片或单段视频，转向完整生产系统的趋势。设计师需要的不只是画面好看，还要保留字体、布局和品牌规范，并快速输出多个尺寸版本。对于这类任务，一个结构化动态图形编辑器可能比画质更高但不可预测的视频模型更实用。

Motion 也靠近正在成形的智能体生态。如果其工作流可以被编码智能体调用、修改和串联，它就可能成为自动化广告生产链中的一个模块，而不只是独立创作界面。这会对传统动态图形软件的中低端市场形成压力。

不过，产品仍处于早期阶段。Krea 尚未证明 Motion 能否处理复杂时间轴、专业规模的可编辑场景，以及长期使用的成本。现阶段真正值得观察的，不是它能否立即取代 After Effects，而是 AI 原生动态图形是否会从“生成短片”转向“生成结构化、可编程场景”。

Uncle Cat 判断

比免费试用更关键的是 Krea 尚未公布 API 和授权细节；在此之前，Motion 仍是有潜力的工作流演示，而非生产基础设施。
