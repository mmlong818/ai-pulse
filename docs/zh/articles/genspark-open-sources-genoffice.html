Genspark 开源 GenOffice：面向 PC 与 Mac 的 AI 办公套件

Genspark 发布 GenOffice，自称首个功能完整的开源 AI 办公套件，Windows 与 macOS 均可免费使用且无广告。

一套免费办公软件，Agent 是原生部件

8 月 3 日，Genspark 宣布开源 GenOffice，官网博客文章标题为《GenOffice：首个开源 AI 办公套件》，同时在 X 上连发数条动态。公司称这是全球首个功能完整、面向 PC 与 Mac 的开源 AI Office，对所有人免费、无广告，并打包了桌面办公软件应有的编辑工具集。

伴随发布，Genspark 在其多人协作 Agent 空间 GenTeam 中开了一个 GenOffice 群聊：用户在里面描述自己想要什么，由 Agent 直接动手实现——相当于把功能需求变成一条实时开发队列，让社区直接影响路线图。截稿时，该博客文章从站外无法公开读取，因此许可协议与代码仓库地址尚无法独立核实，目前依据的是官方一方信息。

这个形态为什么值得注意

过去一年 Genspark 一直在给别人的软件装 Agent：4 月的 AI Workspace 4.0 把 Agent 以原生插件形式塞进 Word、Excel 和 PowerPoint，随后又宣布与微软合作，将 Agent 接入微软生态。GenOffice 把这层依赖反了过来——不是去自动化 Office，而是自己交付文档界面本体，Agent 从外挂变成内生组件，并且免费送出。

为什么重要

迄今为止，AI 原生的生产力工具要么以插件形式寄生于既有办公套件，要么是封闭的云产品。一套开源、可本地安装、围绕 Agent 设计的办公软件是另一种赌法：文档格式、自动化层与编辑界面全部可审计、可 fork，这对不能把在办文件上传到厂商云的组织很关键。它也恰好与阿里同周把企业办公 Agent 推入公测撞在一起，说明 Agent 竞争的争夺点正从模型转向真正干活的那个工作台。GenOffice 究竟是产品还是姿态，取决于尚未公开的细节：许可证、仓库，以及这套软件有多少部分真能由社区维护。
