谷歌推出 Gemini Decisions API，单次处理千项多模态判断

Gemini Decision 1 可在一次请求中处理最多1000项多模态判断，瞄准模型路由、策略检查等高频基础环节。

发生了什么

谷歌发布 Gemini Decisions API，并推出专门处理封闭式判断的 Gemini Decision 1。开发者可以提交一份文本、图片、音频、视频或 PDF，同时提出最多1000个是非题、选择题或评分标准问题。

谷歌称，该模型会返回概率和置信度，端到端延迟约为150至250毫秒。服务已通过 Gemini API 在 Google AI Studio 中开放，输入价格为每百万 token 0.10美元，输出 token 不另收费。

为什么值得关注

这项产品瞄准的是应用里的“隐形基础设施”：选择调用哪个工具、判断文档是否符合政策、决定请求应交给哪个模型，以及检查检索结果是否真正相关。这些任务通常不需要长篇回答，却要求结果稳定、延迟可控。

批量处理机制尤其关键。企业可以让同一份多模态内容一次性接受多项检查，减少重复调用生成模型的次数，也能简化 Agent 的编排流程。不过，谷歌目前没有公开证明它在准确率上已经超过传统分类器或人工审核。

尚待验证

Gemini Decisions API 面向封闭集合判断，并不是通用推理模型的替代品。置信度数字也必须经过校准，只有当它能真实对应错误概率时才有业务价值。谷歌展示了明确的应用方向，但生产环境中的稳定性仍要靠独立测试确认。

对 Agent 开发者而言，这次发布释放出一个信号：模型厂商正在把“做决定”封装成独立能力，而不是让每一步都退化成聊天请求。
