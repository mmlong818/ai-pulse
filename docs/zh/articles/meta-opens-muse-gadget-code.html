Meta 开放 Muse 设备代码，试水社区自制 AI 硬件

Meta 开放 Muse 设备代码，支持 ESP32 和树莓派，让开发者把个人 AI 代理接入屏幕、传感器与家用设备。

发生了什么

Meta 开放了一套代码，让开发者可以为个人 AI 代理 Muse 自制硬件设备。项目支持常见的 ESP32 开发板和树莓派，并可连接显示屏、按钮、传感器及执行器。

Meta 展示的用途包括电子墨水提醒屏、通过 HDMI 连接的大屏，以及类似自制 Muse Charm 的小型触摸设备。公司还公布了 Muse Home Link，这是 Meta 自行制造的一款小批量设备，共生产 5000 台。根据用户的具体配置，Home Link 可以让 Muse 控制灯光、电视和打印机等家庭设备。

为什么重要

这次开放意味着 Meta 正在把 Muse 从应用和桌面客户端，扩展为可运行在实验性硬件上的软件层。代理只有在能够感知并影响现实环境时，才可能真正超越聊天窗口中的问答工具。

开放策略也能帮助 Meta 吸引爱好者和开发者，创造公司自身不会优先开发的硬件形态。如果社区技能不断增加，Muse 可能成为一个平台，而不只是一个封闭的消费级助手。

限制同样明显。Meta 提醒用户自行承担风险，而接入传感器、家居控制和打印机的社区设备，也会继承桌面代理面临的隐私和权限问题。Meta 很难监控每一个自制设备的故障与误操作。

短期内，5000 台 Home Link 的产品影响有限，但战略意义更大：Meta 正在测试个人代理能否成为横跨屏幕、传感器和执行器的通用软件层。如果开发者积极参与，Muse 就能通过 Meta 没有制造的设备获得分发。

猫叔判断： 5000 台 Home Link 只是试验规模，真正有想象力的是 ESP32 和树莓派接口，它可能让 Meta 把硬件创新外包给社区。
