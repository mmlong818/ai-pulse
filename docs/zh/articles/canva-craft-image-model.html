Canva发布首款自研图像模型Craft，先规划后生成

Canva推出面向设计场景的Craft图像模型，现已在Canva和公开API中提供，重点提升构图、文字与版式控制。

Canva发布首款由 Canva Research 开发并训练的先进图像生成模型 Craft。模型现已接入 Canva，并通过公开 API 提供给外部开发者，意味着 Canva 正从模型整合者走向自研视觉模型提供方。

先规划构图，再生成像素

Canva表示，多数图像模型会从提示词直接生成像素，而 Craft 采用两阶段架构：先规划构图，再渲染图像。目标是改善物体、文字、版式和视觉层级之间的关系。这些因素对设计师而言，往往比单独的写实程度更重要。

公司称，Craft围绕专业设计工作流开发和训练，并根据 DesignArena 排名将 Canva Research 定位为全球第二先进的图像生成 AI 实验室。Canva公开展示的应用方向包括海报、营销素材和其他需要清晰文字与有意布局的视觉作品。

公开 API 的意义同样不小。外部产品和自动化工作流可以调用 Canva 的设计导向生成能力，而不必使用完整的 Canva 界面。随着通用图像模型竞争升温，Canva也借此建立了自己的模型层。

它要做的是设计模型

Craft的重点不只是再增加一个图像生成器，而是重新划定AI辅助设计的边界。提示词生成图片通常只需产出一个看似完成的结果；真正的设计系统还要在反复修改中保留意图、维持品牌一致性，并允许人继续编辑。

当然，Craft尚未证明自己已经解决这些问题。DesignArena 的定位主要来自公司披露，关于可编辑性、文字准确率和多轮一致性的独立测试仍然有限。

为什么重要

Canva覆盖了大量非专业创作者，因此一个围绕版式和沟通设计的模型，可能比单纯提升写实度更快影响日常商业内容。与此同时，API开放也让代理商和软件开发者能够把具备设计意识的生成能力嵌入自己的产品。

猫叔判断： Craft真正押注的是两阶段构图规划；能否扛住真实品牌反复改稿，才决定它不是精致演示品。
