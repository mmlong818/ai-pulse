Anthropic发布Claude Opus 5.5，性能提升同时降本

Anthropic推出Claude Opus 5.5，称其达到Fable 5.1级别表现，运行成本下降40%，并强化网络安全防护。

发生了什么

Anthropic于9月22日发布Claude Opus 5.5，这是Claude 5.5系列的首款模型。公司称，该模型在多数任务上达到Claude Fable 5.1级别的表现，运行成本较Opus 5下降40%；在相同工作量下，生成速度提高30%以上，所需令牌也更少。

Opus 5.5已进入Claude面向个人和企业的产品，并通过API及主要云平台提供。GitHub Copilot、Cursor、AWS和Google Cloud很快接入了这一模型，编程和企业用户可以直接在现有工具中使用。

安全与部署

Anthropic把这次发布同时包装成能力升级和安全更新。Opus 5.5接受了METR、Frontier Design等外部评估，Anthropic称其在公司迄今最全面的对齐测试中取得最好成绩。公司还强调加强了网络安全相关请求的防护，因为更强的编程模型既能帮助防守方，也可能降低滥用门槛。

这次发布的时间点很值得关注。Anthropic近期一直主张放缓前沿模型竞赛，但现在又推出了一款更擅长智能体编程和知识工作的模型，并显著降低使用成本。效率因此也成为安全议题的一部分：更便宜、更快的模型能扩大有益应用，也会让大规模滥用更容易自动化。

为什么重要

Opus 5.5同时提高了模型质量和单位经济性的竞争强度。真正决定其影响力的，不是发布会上的基准成绩，而是它能否在长时间编程任务中保持稳定，以及接入工具、代码仓库和云系统后，安全限制是否仍然有效。
