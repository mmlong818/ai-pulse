月之暗面开源 Kimi K3：2.8 万亿参数权重登陆 Hugging Face

月之暗面在 7 月 27 日 0 点（UTC）如约放出 Kimi K3 全部 2.8 万亿参数权重，采用 Kimi K3 License 许可证，成为迄今最大的开源权重模型。

7 月 27 日 0 点（UTC），月之暗面如约在 Hugging Face 上放出了 Kimi K3 的完整权重：MXFP4 量化格式，体积约 1.4TB，沿用 K2 系列的 Kimi K3 License 许可证。总参数 2.8 万亿，这是迄今为止规模最大的开源权重模型。

规格与成绩

K3 采用月之暗面自研的 Stable LatentMoE 混合专家架构，896 个专家中每个 token 激活 16 个，配备 100 万 token 上下文窗口和原生视觉能力。按官方口径，K3 综合能力仍落后于 Anthropic 的 Claude Fable 5 和 OpenAI 的 GPT-5.6 Sol，但在编码与智能体测评上全面超过 Claude Opus 4.8 和 GPT-5.5；Tom's Hardware 则注意到它在 Frontend Code Arena 基准上压过了 Fable 5。K3 的 API 此前早已上线（兼容 OpenAI 与 Anthropic 接口，输入/输出约 3/15 美元每百万 token），所以这个周末改变的不是"能不能用"，而是"归谁控制"——任何人都可以在自己的硬件上部署它。当然，1.4TB 的体量决定了自托管短期内只属于大型团队和基础设施厂商，要等社区量化版本出来才会真正普及。

落在风暴眼上

发布时机耐人寻味：华盛顿正在讨论对中国开源模型实施"选择性禁令"，英美联合评估几天前刚给 K3 的网络攻击能力打了分；而呼吁美国政府豁免开源模型的《Open Weights and American AI Leadership》公开信，自 7 月 24 日发布以来签署方已翻倍至约 50 家——英伟达、微软、Meta 属首批，Google 与 OpenAI 随后加入，Anthropic 与亚马逊则在所有版本中始终缺席。Hugging Face 官方账号用一句"free the parameters"迎接权重上线。而月之暗面正推进估值约 500 亿美元的港股 IPO，这次开源同时也是一步声势棋。

这件事的分量在于：它把一个政策概念变成了既成事实——全球任何有算力的机构现在都能在本地跑起一个准前沿模型，不必碰任何中国 API。这既拆掉了"数据主权"层面对中国 AI 的疑虑，也让"在 API 层围堵前沿能力"的监管思路失去了支点。
