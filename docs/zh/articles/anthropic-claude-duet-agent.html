Anthropic开放Claude Duet主动式代理研究预览

Anthropic开始测试Claude Duet，让代理主动发现待办、执行任务，并在敏感操作前请求用户批准。

Anthropic开放了Claude Duet的研究预览。这是一款主动式代理，不再只等待用户逐条提问，而是持续处理用户的数字工作。当前产品通过候补名单向美国的Pro和Max订阅用户开放。

Anthropic表示，Duet建立在Claude Opus 5.5之上，可以识别可能需要关注的工作，在后台完成任务，并在需要决策或批准时返回用户。Duet会继承用户 Claude 账户中的记忆、技能和已连接应用，并可使用 Claude Marketplace 中超过 6000 个连接器和插件。

产品设计体现了助手从“回答问题”向“观察工作状态”的转变。对软件团队和知识工作者而言，代理可以收集上下文、检查多个连接来源并连续执行一组动作，而不只是生成一次性答案。但与此同时，安全难题也更复杂：错误可能发生在初始指令之后、最终行动之前的任何环节。

Anthropic称，Duet不会直接看到用户密码或登录令牌，并通过专门的安全机制阻止高度敏感信息被分享。公司也承认，系统可能误判哪些事情紧急。主动式产品尤其需要面对这一点：等待可能错过窗口，过早行动又可能造成更大问题。

目前的研究预览和美国限定范围，说明这仍是一场受控实验，而不是全面商业发布。它的重要性在于产品方向：Anthropic正在验证，一个模型能否成为持续工作的伙伴，同时保持可打断、懂权限并受安全边界约束。如果这一模式成立，代理产品的竞争重点将从聊天质量转向信息不完整时的判断能力。

猫叔判断

Claude Duet最关键的风险不是能否访问连接应用，而是能否判断何时打断用户；Anthropic已承认这项判断仍不稳定。
