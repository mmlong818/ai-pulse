阿里「千问办公」开启公测，企业级 Agent 三端合一

阿里将 QoderWork、MuleRun、悟空三款产品整合为千问办公，桌面端、云端与协同 Agent 打包，底座换成新发布的 Qwen3.8。

三款产品合成一个

8 月 3 日，在 Qwen3.8 发布数小时后，阿里的「千问办公」（QwenWork）开启公测。这款产品由此前独立的 QoderWork、MuleRun 与悟空三条线整合而来，阿里称其为业内首款同时支持桌面端 Agent、云端 Agent 与企业协同 Agent 的产品。

底座模型是同日发布的旗舰 Qwen3.8。目前网页版与独立 PC 客户端已开放，钉钉 PC 端与手机端入口据称近期上线。新用户注册可得 2000 积分，公测首周每日登录还可领取 500 至 2000 积分。

瞄的是企业流程，不是个人效率

阿里的定位相当明确：全面对准企业级市场。除了写文档、做 PPT，千问办公主打的是接入企业内部数据库与既有业务流程，并引入「组织级 Skill」——把一套可复用的操作流程封装起来供全团队共享，让 Agent 的行为方式成为公司层面的基础设施，而不是某个员工私藏的提示词。

这个思路与今年 Agent 市场的走向一致：企业落地的瓶颈很少是模型能力本身，而是权限、数据接入与流程可复现这些「管道活」。把执行拆到能碰本机文件的本地客户端、跑长任务的云端运行时，以及负责团队协同的共享层，本质上是想一次性把三件事都覆盖掉。

为什么重要

阿里现在能在同一天把整条栈端到端交付：前沿模型、编程入口，再加一个同时消费两者的办公 Agent。这种垂直捆绑与微软的 Copilot、谷歌的 Workspace 是同一套打法，但定价与分发走的是钉钉，直插 Microsoft 365 渗透率极低的中国企业市场。对正在评估 Agent 的中国公司来说，问题从「买谁的模型」变成了「以谁的工作台为标准」。公测同时也给阿里提供了一条快速反馈通道，用真实企业负载检验 Qwen3.8 的长周期表现——那正是其模型发布所主张、却尚未在规模上被证明的部分。
