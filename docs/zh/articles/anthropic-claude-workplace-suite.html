Anthropic扩展Claude，进军协作办公工作流

Claude新增白板、表格和数据工具，Claude Meetings也开始向团队和企业用户进行测试版 rollout，Anthropic正把产品从编程助手扩展为协作办公平台。

Anthropic 扩展 Claude 的办公能力，把它从编程和问答助手进一步变成持续协作的工作空间。公司推出 Claude Whiteboards 和 Claude Sheets 测试版，将原有 Dashboards 更名为 Claude Data 并正式开放，同时开始向 Team 和 Enterprise 计划用户推出 Claude Meetings 测试版，让 Claude 参与通话并把讨论转化为后续工作。

更完整的工作界面

Whiteboards 允许用户围绕尚未成形的想法与 Claude 讨论，再把内容整理成带有时间线、负责人和截止日期的可视化计划。Sheets 可以创建和编辑任务跟踪表、预算表等结构化文件。Claude Data 则加入经过认证的查询、数据故事和基于团队指标生成的旁白演示。

Anthropic 还扩展了交互式连接器。用户可以直接在 Claude 对话中打开更完整的外部工具版本，包括 Adobe、Atlassian 和 Box 等集成。公司的目标，是把分散在邮件、文档、表格和专业软件中的工作上下文集中起来。

Claude Meetings 已进入测试版 rollout 阶段，不再只是尚未上线的预告功能。Anthropic 当前帮助文档显示，Team 和 Enterprise 用户可以把 Claude 作为可见参与者加入 Google Meet 通话，让它记录内容、回答问题，并在通话期间创建文档、白板和幻灯片等工作产物。部分组织暂时无法使用该功能；同时，参会者是否同意被转录、录音处理、权限管理以及自动生成任务的准确性仍然是实际问题。

Whiteboards、Sheets 和 Data 面向付费用户开放，企业管理员可以控制部分选项。企业版默认关闭 Whiteboards 和 Sheets，而 Claude Data 计划于 11 月 19 日为企业客户默认开启。

为什么重要

Anthropic 争夺的已经不只是文本生成入口，而是工作被组织和推进的那一层。Claude Code 的上下文管理和产物式工作流，可能帮助它进入非技术团队。但治理仍是关键短板：白板、表格和会议纪要一旦变成行动系统，负责人、权限或数据理解上的错误，就可能直接进入企业运营。
