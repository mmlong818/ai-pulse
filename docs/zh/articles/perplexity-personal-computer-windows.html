Perplexity 桌面智能体 Personal Computer 登陆 Windows

该桌面智能体可读取本地文件、操作 Office 应用，并把子任务分发给 20 多个前沿模型，门槛为每月 200 美元档位。

Perplexity 于 7 月 28 日把桌面智能体产品 Personal Computer 带上 Windows 10 与 11，从研究预览转入正面竞争——而且是在微软自家平台上，直接对上 Copilot。

运作方式

本地应用接收任务描述，连同用户文件与当前活跃应用的上下文一并上传至 Perplexity 云端；那里由一个编排模型（默认 Claude Opus 4.7）把请求拆成子任务，再把每个子任务路由到 20 多个可用模型中最合适的那一个。执行环节落回本机：新建与编辑 Word 文档、更新 Excel 表格、整理文件、跑多步调研、把跨应用的工作流串起来。Perplexity 称它能从 400 多个已连接服务把数据拉进本地文件，并可直接配合现有的 Excel、PowerPoint、Word 与 Outlook。

分发范围有意收窄。Windows 版首先面向 Max 与 Enterprise Max 订阅者，起价每月 200 美元；官方另在可用 Computer 的档位中列出了 Pro。本周 Perplexity 还给 Computer 加入了 Model Council，允许用户用多个前沿模型跑同一份分析，再得到一份带引用的汇总结论；并把月之暗面的 Kimi K3 接入产品，且仅托管于美国服务器。

为何重要

桌面智能体是智能体叙事撞上最硬约束的地方：真实文件系统、私有文件格式、以及一堆没有干净 API 的应用。Perplexity 的答案在架构上很特别——它并不训练自己编排的那些模型，而是押注「租用整片前沿并做路由」优于「自己拥有一个」。这让该产品成为一次实盘检验：一个模型中立的中间层，能否在操作系统厂商亲自内置助手的情况下守住阵地。

定价是另一个信号。Windows 入门档每月 200 美元，意味着 Perplexity 把 Personal Computer 定位成按席位替代若干小时知识工作的产品，而非消费级附加功能——竞争对手此前用在编码智能体上的那套叙事，如今被搬到了通用办公桌面。至于「以这个价格换取本地文件与应用访问权」能否通过企业安全审查，仍是悬而未决的问题。
