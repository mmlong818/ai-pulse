Meta发布Muse Ember，主打低成本智能体执行

Meta推出最小的Muse模型，面向高频智能体任务，提供百万令牌上下文和适合大规模部署的价格。

发生了什么

Meta发布Muse Ember，这是该公司目前最小、最高效的Muse模型，目标任务包括工具调用、路由、信息抽取、文档解析和编程子任务。模型已通过Meta Model API和Muse Code开放，API标识为muse-ember-1.0。

Meta给出的价格是每百万输入令牌0.10美元、每百万输出令牌0.50美元，缓存输入价格为0.004美元。模型支持百万令牌上下文窗口和最多512,000个输出令牌，开发者可以在一次调用中处理大型代码库或文档集合。

Meta将Ember定位为更大Muse模型的低成本补充，而非全面替代品。公司引用Artificial Analysis数据称，Ember在最高推理档位下的AutomationBench-AA得分为37.8%，高于同一比较中Claude Haiku 5.5的13.9%和GPT-6 Luna的20.2%。Meta还表示，Ember达到Haiku最佳成绩时，单任务成本约只有三分之一。

为什么重要

这次发布显示，模型竞争正在转向数千次小决策的经济性。智能体在路由、检查、格式化和调用工具上消耗的令牌，往往比回答一个复杂问题更多。如果低价模型能稳定完成这些步骤，企业就可能把智能体部署到更多产品和工作流中。

不过，相关跑分仍需谨慎看待。核心数据由Meta选择并发布，结果也会受到推理档位和运行框架影响。但价格是真实且即时可用的。若Ember在Meta以外的测试中也能保持稳定表现，它可能改变长期运行型智能体的成本门槛。
