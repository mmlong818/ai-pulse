阶跃星辰开源Step Code，覆盖编程交付完整流程

阶跃星辰开源Step Code编程智能体，支持从代码修改、测试到发布，并在长流程任务中取得较高通过率。

发生了什么

阶跃星辰于9月22日以MIT许可证开源Step Code v0.1.0。这款命令行智能体试图覆盖完整的软件开发流程：读取代码库、修改文件、运行测试、修复失败结果，并发布可用产物。

阶跃星辰称，Step Code在Terminal-Bench 2.1中完成了89项任务中的72项，通过率为80.9%。在其对比测试中，这一成绩与最高分并列，同时使用的令牌少于其他并列系统。在公司自建的150项Multi-Frame长流程测试中，Step Code完成110项，成绩为73.3%，并在六套测试框架中保持最低令牌消耗。

项目还集成了StepPage，可将本地静态网站一键发布为可分享链接，并提供版本管理和回滚。Step Code支持macOS、Linux和WSL，Windows支持目前仍处于测试阶段。

为什么重要

Step Code的价值在于，它把智能体定义为交付系统，而不只是代码补全工具。产品边界延伸到了执行、验证和部署，正好对应用户对长流程编程任务的期待：少看守、能收尾、交付结果。

MIT许可证也降低了开发者检查、修改和接入私有工作流的门槛。即使阶跃星辰的底层模型还没有OpenAI或Anthropic那么广泛分发，公司也可以借助工具和开发者社区参与全球竞争。

不过，现有证据仍然有限。Step Code目前只是0.1.0版本，基准结果来自阶跃星辰自己的评测，Windows支持也不完整。接下来最关键的是，外部开发者能否在混乱的真实代码库和生产系统中复现这种可靠性。
