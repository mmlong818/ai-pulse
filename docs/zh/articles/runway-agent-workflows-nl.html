Runway 为 Agent 加入自然语言 Workflows

Runway 让创作者用自然语言在 Runway Agent 中构建、运行和修改节点式 Workflows，把搭建生成流水线变成一句话的事。

发布内容

7 月 24 日，Runway 在 Runway Agent 中推出 Workflows 功能，用户可完全通过自然语言指令来创建、运行和编辑其节点式生成流水线。创作者无需手动连线节点，只要描述想要的多步输出——把图像、视频与剪辑操作串联起来——Agent 便会相应地搭建或修改工作流图。Runway 称目标是“更大规模地产出更高质量的结果”，并表示功能即刻可用。

在 Runway 体系中的位置

Runway 于 2025 年底推出节点式 Workflows 编辑器，用于构建可复用的自定义创作流水线；2026 年初又推出 Runway Agent，作为其媒体模型的对话式前端。本次更新把两者融合：既保留节点图的结构化能力，又具备“一句话说清需求”的易用性，从而降低搭建复杂、可复用视频/图像流水线的门槛，同时保留专业用户所依赖的控制力。

更大的趋势

这次发布契合 AIGC 工具与智能体界面正在发生的融合。过去创作软件要求用户学习其节点系统与参数面板，如今智能体越来越多地把“意图”直接翻译为结构化操作——这一转变同样体现在 Midjourney 的编辑工具，以及能从提示词生成构建流水线的编码智能体上。

意义

节点式工作流是认真创作者实现一致性与规模化的方式，但其复杂度将许多人拒之门外。通过让智能体用语言撰写并修订这些图，Runway 试图把可复用、可上生产的生成流水线开放给更广泛的创作者群体，也借此在“用更强智能体层包裹生成能力”的竞赛中不掉队。
