Ideogram 联手 Pruna 推出每张 0.003 美元的图像模型

P-Image-Ideogram 提供四档质量模式、原生 1K 与 2K 输出、3 至 8 秒出图，直接瞄准规模化生产的图像流水线。

Ideogram 周四发布 P-Image-Ideogram，这是与推理优化创业公司 Pruna AI 联合开发的文生图模型家族，主打成本与速度，而非单纯拼画质上限。

发布内容

该系列提供极低、低、中、高四档质量模式，开发者可在同一套 API 内按需在画质与价格之间取舍。模型原生支持 1K 与 2K 分辨率及多种画幅比例，出图耗时 3 至 8 秒，价格低至每张 0.003 美元。它还支持 JSON 结构化提示词与版面控制——这些能力面向的是程序化流水线，而不是交互式创作。官方在发布示例中重点展示了照片级写实、文字渲染与风格多样性，其中文字排版一直是 Ideogram 最强的差异化能力。

Ideogram 的核心主张是一个帕累托论证：在 DesignArena 的盲测人类投票图像榜单上，P-Image-Ideogram 同时推进了"质量对成本"和"质量对速度"两条前沿曲线，即榜上没有任何竞品能做到既更便宜又更好、或既更快又更好。该公司并未宣称拿下绝对画质第一。

首日分发铺得很开。除自家 API 外，模型已在 ComfyUI、Replicate、Runware、Cloudflare、Leonardo AI、Picsart 和 Magnific 上线，Replicate 等平台在发布数小时内即宣布可用。此前 Ideogram 刚宣布与 AMD 合作，用 Instinct 加速器为其开源权重的 Ideogram 4.0 提供推理服务，显示出该公司正试图掌控自己的推理成本结构。

为何重要

图像生成的竞争重心，已经从"模型能不能画出这个场景"转向"规模化生产这个场景要花多少钱"。每张 0.003 美元、十秒内出图，改变的是那些每天生成数千张素材的应用的账本——电商商品图、广告素材 A/B 测试、游戏与 App 资源流水线——在这些场景里，决定天花板的是单张成本而非边际美感。与 Pruna 的联名也说明，专做压缩与推理优化的厂商正从下游优化者变成前沿消费级模型的共同作者。
