OpenAI 发布面向长流程任务的 GPT-6 Astra

新旗舰模型提供105万词元上下文、电脑操作和更强编程能力，但因网络安全风险采取分阶段受限开放。

从回答问题转向执行工作

OpenAI 开始推出新旗舰模型 GPT-6 Astra，主要面向长流程的软件开发、研究和电脑操作任务。首批访问仅向部分机构开放，包括可信访问计划中的企业客户；API 以及 ChatGPT Plus、Pro、Business 和 Enterprise 套餐将在随后数日逐步获得使用权限。

Astra 支持文本和图像输入，上下文窗口达到105万词元，单次最多输出12.8万词元。它可调用电脑操作、网页与文件搜索、托管命令行、代码执行、补丁修改、MCP 连接及图像生成等工具。OpenAI 还加入异步工具调用和执行中追加指令的能力：外部工具尚未返回时，模型可以继续处理其他工作，用户也能在任务中途纠正方向。

其 API 定价为每百万输入词元10美元、输出词元50美元；提示超过27.2万词元后，实际费率还会提高。早期独立评测对性价比的判断并不一致。Artificial Analysis 观察到部分智能体和事实可靠性指标提升，但称 Astra 在最高推理档位比 GPT-5.6 Sol 贵75%，按单位任务成本衡量时经常落后于前代。

能力提升伴随访问限制

OpenAI 称 Astra 在编程、专业工作流和电脑操作方面取得显著进步，其中 DeepSWE v1.1 得分75.2%，离线电脑操作基准 OSWorld 2.0 得分72.6%。与此同时，Astra 是 OpenAI 首个被评为“关键级”网络安全能力的模型，因此采用受限发布。公司强调，最强网络安全评测所用配置与默认生产版本不同，正式服务还叠加了监控和访问控制。

为何重要

Astra 把前沿模型竞争进一步推向能在浏览器、命令行和专业软件之间持续工作的系统。它能否成为真正的生产力跃迁，取决于基准优势能否延续到漫长而混乱的真实任务，以及安全限制能否在实用性和网络风险之间维持平衡。
