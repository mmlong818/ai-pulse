Cursor 推出印度专属月付 649 卢比套餐，含云端智能体

Cursor 首个本地化定价方案打包 Composer 2.5、Grok 4.5、自主云端智能体与 iOS 客户端，价格约为 Pro 的三分之一。

本地定价，但功能不缩水

Cursor 7 月 28 日推出 Cursor Start，一个仅面向印度开发者的月付 649 卢比套餐，按当前汇率约合 7 美元，而全球 Pro 版为 20 美元。该套餐以卢比计价，支持 UPI 或银行卡支付——此前印度用户只能以美元付费，本地支付是长期诉求。

这不是一个功能被砍空的入门版。套餐包含 Cursor 所称的「充足额度」，可使用其两款性价比模型：自研 Composer 2.5 与 xAI 的 Grok 4.5，覆盖网页、桌面、CLI 与 iOS 客户端。同时提供可在用户离开时自动构建、测试并提交 PR 的云端智能体，支持在手机上启动和操控这些智能体、回到桌面继续接手，并完整支持插件、MCP server、hooks 与 skills。Start 不包含的是 OpenAI 与 Anthropic 的前沿模型，以及 Bugbot、Auto Mode 等更高层功能。

Cursor 表示，过去一年其印度用户规模增长约两倍，达到 300 万开发者以上，使印度成为其第三大市场，也是重度用户密度最高的国家。负责亚太业务的 Simon Green 将此举定位为「把商业模式调到合适尺寸以驱动规模」，而非单纯降价。

发布之际，Cursor 本身正处在被收购过程中。SpaceX 于 4 月同意以 600 亿美元股票收购该公司，预计第三季度完成交割，在此之前 Cursor 保持独立运营。

为何重要

编码智能体此前的定价基准一直是美国薪资水平，结果是开发者数量最庞大的市场反而用不上最强工具。Start 是头部智能体厂商第一次用「为本地重新设计的套餐」而非「同一 SKU 打区域折扣」来正面回应这个问题——更值得注意的是，它把云端智能体和手机操控放进了入门档，而不是当作高价功能。如果转化跑通，从 GitHub 到阿里 Qoder 都将面临跟进压力，智能体编码的竞争重心也会向亚洲的量级市场迁移。
