Meta 发布终端编码智能体 Muse Code 及配套模型 Muse Spark 1.2

Meta 超级智能实验室上线 Muse Code 测试版，配套模型定价每百万输入 token 1.25 美元，并推出「用数据换折扣」的贡献者档。

8 月 5 日，Meta 超级智能实验室（Meta Superintelligence Labs）发布终端编码智能体 Muse Code 测试版，同时推出配套模型 Muse Spark 1.2。官方称该模型与智能体框架是「联合训练」的，而非事后适配。

架构设计

Muse Code 在 macOS 与 Linux 上通过一条命令安装。它最显著的设计选择是持久化的异步后台智能体——在整个会话期间保持活跃，而不是每个任务临时拉起再销毁。Meta 表示这样可以减少重复的上下文收集，也降低开发者在长链条多步任务中需要人工纠偏的次数。当任务足够复杂时，智能体会在相互隔离的 git worktree 中并行推进，不触碰用户当前的工作目录；内部测试中它同时完成了六个游戏功能且没有产生合并冲突。

运行时会把每一次模型调用与动作写入本地的追加式事件日志，因此崩溃后可以精确重放恢复。内置技能包括需审批的规划 /plan、在执行前对方案做对抗性压测的 /grill，以及目标跟踪 /goal。

模型与定价

Muse Spark 1.2 在编码任务上显著加大了训练算力投入。Meta 自家的发布图表显示，该模型在 Terminal-Bench 2.1（89 项任务）、DeepSWE v1.1（覆盖 91 个仓库、5 种语言的 113 项任务）以及由 440 个真实 PR 衍生的内部基准上均排在 Claude Opus 5 之后位列第二——Meta 同时说明，其框架未必针对第三方模型做过调优。在一项长时程测试中，该智能体在英伟达 Hopper 硬件上对 KDA 与 MLA GPU 内核做优化，历时约 24 小时、调用工具超过 1000 次。

API 定价为每百万输入 token 1.25 美元、输出 4.25 美元。Meta 还推出「贡献者档」，价格降至 0.10 与 0.20 美元（输入便宜 12.5 倍、输出便宜 21.25 倍），代价是授权 Meta 用你提交的提示与生成内容训练后续模型，且速率限制为每分钟 60 次请求，而标准档为 3000 次。该模型不提供权重下载，属于托管服务依赖。

为何重要

Meta 由此正面对上 Claude Code 与 OpenAI Codex，切入点是价格。第三方评测将 Muse Spark 1.2 的成本折算为每项 Intelligence Index 任务约 0.40 美元，在同等能力档位中属于最便宜的一档。更值得注意的是那个「数据换折扣」的档位：它把开发者的使用数据明确标了价，企业采购方必须把它和自己的代码保密要求放在一起权衡。
