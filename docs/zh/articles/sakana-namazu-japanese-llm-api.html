Sakana AI 上线日语专用大模型 API「Namazu」

东京实验室 Sakana AI 基于月之暗面开源的 Kimi K2.6 微调出日语特化模型 Namazu，正式开放商用 API。

中国开源底座，调成日本职场口吻

8 月 3 日，Sakana AI 开始提供日语特化大模型 API「Namazu」（鲶鱼）。这家东京实验室表示，模型以开源权重模型——月之暗面的 Kimi K2.6——为基座，再用自有数据做微调，使其适配日语表达与日本业务语境，包括自然的敬语和商务惯例。微调同时约束输出行为：抑制偏见，并对特定敏感话题做回避处理。

跑分方面，Sakana 称 Namazu 在数学（AIME26）与编程（LiveCodeBench v6）上基本维持基座水平，而日语相关评测提升明显：在政治中立性测试 FairPoliticsQA 上，成绩从 34.10% 升至 56.30%。

定价与打法

Namazu 采用按量付费、无月费：每百万 token 输入 0.95 美元、输出 4.00 美元；联网搜索每千次调用 7 美元，代码执行每小时 0.12 美元。结算币种为美元，日元开票仅面向企业方案。受 GDPR 合规工作尚未完成影响，该 API 目前不在欧盟／欧洲经济区、英国与瑞士提供。

Sakana 自己列出的场景都很「不性感」，但量大：每周一早上自动送达的市场调研报告，从制定调研计划、反复联网检索到交叉核对与撰写全程无人介入；客服场景则从问询应答一路做到订单数据的汇总分析；创意场景的演示是只给一句「海洋世界」的题目，模型自行决定呈现什么意象、用联网搜索收集参考图，再编排出约一千条鱼的鱼群动作。

为什么重要

真正值得注意的是供应链本身。日本头部 AI 实验室，如今把一个中国开源模型作为本国语言商用 API 的底座，竞争点落在价格与文化贴合度，而非前沿能力。这是近期关于「中国开源权重到底带来了什么」最直白的一个例证：无需自建基础训练，几个月就能做出一款主权语言产品。它同时给东京抛出一个政策问题——日本把 AI 自主可控写进了目标，而 Namazu 在商业上足够「日本」，底座权重却是别人训出来的。
