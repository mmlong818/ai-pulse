Seedance 2.5上线草稿模式，先低成本试片再生成终版

字节跳动为 Seedance 2.5 增加 480p 草稿流程，创作者可先验证镜头，再生成 1080p 正式视频以减少试错成本。

发生了什么

字节跳动为 Seedance 2.5 增加 Draft Mode，把 AI 视频生成拆成低成本预览和正式渲染两个阶段。创作者先生成 480p 草稿，检查构图、运镜、主体动作、对白和节奏；确认镜头方向后，再通过草稿任务 ID 生成 1080p 终版，而不必完全重新抽卡。

草稿阶段的提示词、参考素材、时长、画幅和随机种子等关键条件会被带入终版任务。字节跳动给出的示例称，5 秒视频平均尝试四次时，草稿模式可节省约 57% 成本，并将整体速度提高近一倍。其他报道提到，在特定使用方式下节省幅度最高可达 77%，实际收益取决于用户原本会丢弃多少次尝试。

为什么重要

AI 视频制作的成本痛点往往不在最后一次渲染，而在发现镜头方向错误之前已经消耗的多次高分辨率生成。Draft Mode 把构图和动作验证放到便宜阶段，逻辑上更接近影视制作中先做粗剪和预演、再进行最终渲染的流程。

这不是简单增加一个低分辨率选项，而是把模型的不确定性纳入生产流程。平台开始帮助用户完成筛选、修改和定稿，而不只是出售一次次孤立生成。这对广告公司、短剧团队、品牌内容部门和批量调用 API 的客户都有现实价值。

但一致性仍是限制。1080p 终版依然需要第二次推理，细节、文字、产品形状或人物特征可能发生变化。草稿模式能降低试错价格，却不能保证批准的镜头完全原样保留。它能否成为专业制作的默认环节，取决于用户是否接受这笔一致性成本。
