OpenAI拟收购Pierre，强化Codex代码协作链

OpenAI计划收购开发者工具公司Pierre，将代码浏览、审查和存储能力纳入面向智能体的Codex工作流。

交易内容

OpenAI宣布将收购Pierre Computer Company。Pierre开发了Code Storage，以及一系列用于代码浏览和审查的开源工具。交易仍需满足惯常交割条件并获得监管批准，在完成前双方仍将保持独立运营。

Pierre的Trees和Diffs库已经被Codex使用。Trees帮助开发者浏览大型代码仓库，Diffs则支持快速查看变更并进行行内修改。Pierre还推出了Highlights语法高亮工具，可在代码输入或智能体持续输出时实时更新；Code Storage则通过Git保存代码并跟踪版本历史。

OpenAI将这笔收购放在软件开发方式变化的大背景下解释。OpenAI工程团队正在建设内部源代码管理后端Pando，用于支持人类与智能体并行工作。Pierre带来的则是代码审查和历史管理等更接近用户的一层工具。

战略意义

这笔交易的重要性不在于Pierre的规模，而在于它瞄准了智能体工作流中仍然缺失的一层。编码智能体可以快速生成分支和补丁，但企业仍需要检查、比较、修改并保存这些变更。通过把代码浏览、审查和版本历史进一步靠近Codex，OpenAI试图控制从智能体第一次改动到软件上线的完整路径。

OpenAI表示，Pierre的开源项目将继续开源，现有Code Storage客户在交易完成后也可以继续使用服务。这能降低短期冲击，但长期问题在于，这些工具能否保持中立基础设施属性，还是会越来越围绕Codex定制。

对开发者而言，这笔收购说明智能体竞争已超出模型能力本身。最终占据优势的产品，可能还包括帮助团队判断哪些机器生成改动值得合并的界面。
