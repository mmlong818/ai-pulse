Anthropic重做Claude Code Projects，让多智能体并行协作

Anthropic推出重做版Projects，让Claude协调云端编码会话、共享记忆，并跨多个代码库并行提交修改。

发生了什么

Anthropic将Claude Code Projects从“文件夹加对话”重做成面向长期软件任务的协调层。用户只需描述目标，Claude便会把工作拆分到多个并行线程中执行。

每个线程都是独立的Claude Code云端会话，拥有自己的代码分支和工作副本。协调器负责分派任务、检查结果、处理依赖关系，并汇总最终成果。比如，针对结账接口延迟，Claude可以同时让不同线程分析各个端点、测试优化方案并准备拉取请求。

新版Projects还加入共享项目记忆。不同线程产生的决定、限制条件和工作偏好会持续沉淀，Claude可以记住发布日期为何推迟、某项改动需要谁批准等背景。项目同时提供文件与产物库，用户可以在主对话中查看、调整进度，也可以通过手机介入。

开放范围与限制

该功能以测试版形式首先开放给使用Claude Code云端会话的部分Pro和Max订阅者。原有Projects仍可继续使用，后续将扩大到Claude、Team和Enterprise用户。目前线程运行在Anthropic云端，不能访问用户本地网络中的文件和工具。

并行运行也会更快消耗用量额度。共享记忆和分支机制降低了交接成本，但多个智能体同时修改同一代码区域时，仍会产生普通的合并冲突。

为什么重要

这次更新把编码智能体从逐条请求推进到项目级委派。真正值得关注的不是多了一个界面，而是多个自治工作流开始被包装成软件生产的基本单元。它能否减少人工协调、审查和返工，最终仍取决于编排质量与使用成本。
