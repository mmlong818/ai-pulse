Cloudflare 推出 Kitesurf：为智能体重造的无 Chromium 浏览器

该浏览器完全跑在 Workers 的 V8 隔离环境中，官方称常见智能体任务下 CPU 与内存开销仅为 Chromium 的三分之一到七分之一，代价是耗时约 1.7–1.8 倍。

8 月 6 日，Cloudflare 发布 Kitesurf——一款为 AI 智能体设计的网页浏览器，完全运行在 Cloudflare Workers 的 V8 隔离环境中，底层没有 Chromium。目前通过 Browser Run 免费开放公测，按账号设有额度限制。

架构

Kitesurf 砍掉了浏览器中为人类而生的部分——标签页、扩展、像素级 60fps 合成渲染，只保留智能体真正消费的东西：机器可读的页面内容、更低的 token 开销、廉价的并发与隔离性。系统分为四部分：Engine 通过 Chrome DevTools Protocol 与 HTTP REST 管理会话；PageScript 基于 Rust 渲染引擎 Blitz 与 Firefox 的 Stylo CSS 解析器处理 DOM 与布局；PageRenderer 负责输出 JPEG、PNG 或 PDF；SandboxOutbound 则执行网络策略、CORS 与 Cookie 管控。

Cloudflare 称，在截图、HTML 抽取等典型智能体负载下，相比 Chromium 其 CPU 占用降至 1/3.1–1/3.8、内存降至 1/4.7–1/7.0，代价是墙钟耗时增加约 1.7–1.8 倍。官方称该引擎已通过超过 21.5 万项 Web Platform Tests。现有 Puppeteer、Playwright 与 MCP 客户端只需加一个 browser=kitesurf 参数即可切换，Cloudflare 表示后续计划开源以支持自托管。

为什么重要

「让智能体用浏览器」已成为默认能力，而业界标准做法——每个会话起一个无头 Chromium——从来就不是为此设计的。Chromium 的开销大头是智能体根本不看的渲染保真度，这让单智能体浏览贵到直接限制产品能承受的并发会话数。Kitesurf 的取舍很明确也不常见：接受近乎翻倍的延迟，换取数倍的资源节省——当智能体无人值守长跑、真正的约束是成本而非响应速度时，这个方向是对的。

战略层面看，Cloudflare 是在把浏览器做成自己出售的基础设施，而不是让每家智能体厂商各自重造一遍——和它当年用 Workers 做算力是同一套打法。若开源承诺兑现，更深远的影响可能是：多年来第一次，有一款可信的非 Chromium 引擎进入了规模化生产使用。
