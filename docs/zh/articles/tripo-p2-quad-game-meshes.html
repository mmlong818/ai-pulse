Tripo P2.0 预览版直出四边面，瞄准游戏资产生产

Tripo 推出可生成原生四边面拓扑的 P2.0 预览版，最高支持2.5万四边面，重点服务角色与实时游戏资产。

把拓扑质量纳入生成过程

中国三维生成公司 Tripo 发布 Tripo P2.0 公开预览版，核心变化是能够直接生成原生四边面拓扑。该版本最高支持5万个三角面或2.5万个四边面，已在 Tripo Studio 开放体验，每位用户可免费生成两次。

多数图生3D系统首先比拼外形和纹理是否接近参考图，但对于实际制作团队，模型内部不可见的网格结构同样关键。杂乱的三角面、冗余几何以及位置不合理的边线循环，都会让一个看起来不错的模型难以继续绑定骨骼、制作动画或导入游戏引擎。

Tripo 表示，P2.0 会在关节周围生成更平滑的边线循环，在平坦表面保持整洁的四边面，并把更多几何密度分配给细节区域。公司将其定位于游戏角色和其他实时资产场景，因为拓扑结构会直接影响模型变形、骨骼绑定、渲染开销，以及投入生产前所需的人工清理工作。

目前仍是预览版本

P2.0 尚未作为正式生产版本发布。现有公告还不足以证明它能否稳定处理复杂输入、不同体型下的边线走向是否适合动画，以及生成结果与人工重新拓扑的模型相比处于什么水平。与此同时，上一代 P1.0 已向所有用户开放，可作为拓扑新能力测试期间更成熟的选择。

为何重要

原生四边面生成解决的是 AI 三维演示与可用生产资产之间的一项现实瓶颈。重新拓扑是传统三维流程中专业性强、耗时较长的环节；如果模型能够显著减少这部分工作，游戏、虚拟世界和互动广告的制作周期都有望缩短。此次发布也反映出生成式3D竞争正在转向：仅仅“看起来像”已经不够，厂商开始直接优化几何可编辑性，以及与后续制作管线的兼容程度。
